================================================================================
TROUBLESHOOTING
================================================================================

If you encounter issues:

1. Database Connection Error:
   - Check config/database.yml
   - Ensure MySQL is running
   - Create database: rails db:create

2. Asset Compilation Error:
   - Run: rails assets:clobber
   - Then: rails assets:precompile

3. Gem Compatibility Issues:
   - Run: bundle clean --force
   - Then: bundle install

4. Migration Issues:
   - Check db/migrate/*.rb files
   - Run: rails db:migrate:status
